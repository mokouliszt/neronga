# neronga

**[Japanese README / 日本語版](README.ja.md)**

A Windows desktop application to scan, inspect, and organize scattered configuration files generated by AI coding agents and developer tools — including Claude Code, OpenAI Codex CLI, GitHub Copilot, Google Antigravity / Gemini CLI, Cursor, Windsurf, Cline, and more.

These tools place **skills directories**, **custom instruction files** (`CLAUDE.md`, `AGENTS.md`, `copilot-instructions.md`, etc.), and **MCP server configs** across your user profile and project repositories. As configurations accumulate across multiple tools and repositories, keeping track of active settings and past changes becomes difficult.

neronga provides a centralized view to inspect these files, temporarily "make transparent" (stash/hide) unused settings, and edit instructions or MCP configs directly with a self-contained, local Git revision history — without relying on external services or network connectivity.

## Features

- **Zero-configuration presets for popular tools.** Includes a built-in catalog of default paths for Claude Code, OpenAI Codex CLI, GitHub Copilot, Google Antigravity, Cursor, Windsurf, Cline, Roo Code, Continue.dev, Amazon Q Developer CLI, JetBrains AI Assistant (Junie), and the cross-tool `AGENTS.md` / `.agents/skills` specification. All paths can be added, customized, disabled, or removed.
- **Global and per-project scanning.** Global configurations under your user profile are detected automatically on launch. Registering project root directories in Settings enables recursive scanning for repository-level files like `CLAUDE.md`, `.mcp.json`, and `.github/copilot-instructions.md`.
- **Transparency (safe stashing).** Temporarily deactivate unused skill directories or instruction files by clicking "透明化" (Make Transparent). Instead of deleting them, neronga safely moves them to `%LocalAppData%\neronga\vault\<uuid>\`. Stashed items can be restored to their original locations at any time from the "透明化済み" (Transparent) tab.
- **Self-contained revision history.** Edit instruction files and MCP configurations directly inside the built-in editor. Every save is automatically committed to an embedded local Git repository (`%LocalAppData%\neronga\history`, powered by [LibGit2Sharp](https://github.com/libgit2/libgit2sharp)). No external git executable or GitHub account required — all changes stay strictly on your machine. Includes history browsing, colorized diff views, and one-click rollback.
- **Modern Fluent Design UI.** Built with [WPF-UI](https://github.com/lepoco/wpfui), featuring a custom yellow-and-gray theme, Mica backdrop, and dark/light mode support.
- **Japanese and English UI.** Switch languages from Settings. The change applies immediately without restarting, and covers the built-in path catalog labels as well.

## Download

Download the standalone `neronga.exe` from the [Releases](../../releases) page. No installer or pre-installed .NET runtime is required.

## Building from source

Requires [.NET 10 SDK](https://dotnet.microsoft.com/) or later. While the application runs exclusively on Windows, the build process is supported across Windows, macOS, and Linux.

```bash
git clone https://github.com/mokouliszt/neronga.git
cd neronga/src/Neronga
dotnet publish -c Release
```

The standalone executable will be generated at `bin/Release/net10.0-windows/win-x64/publish/neronga.exe`.

## Data Storage

All data managed by neronga is stored locally under `%LocalAppData%\neronga\`:

| Path | Purpose |
| --- | --- |
| `config.json` | Path catalog, project roots, and application settings (theme, UI language) |
| `vault\<uuid>\` | Stash storage for transparent items (each item has its own directory containing a `__neronga_meta.json` with original path metadata) |
| `history\` | Private embedded Git repository storing the complete version history of files edited in neronga |

All data remains strictly local; nothing is transmitted externally.

## Tech stack

- .NET 10, WPF, [WPF-UI](https://github.com/lepoco/wpfui) (Fluent Design controls)
- [LibGit2Sharp](https://github.com/libgit2/libgit2sharp) (Embedded local revision history)
- [CommunityToolkit.Mvvm](https://github.com/CommunityToolkit/dotnet) (MVVM architecture)

## Default Path Notes

Configuration file paths for third-party tools may evolve over time and vary by environment. Default paths for major tools (including Claude Code, OpenAI Codex CLI, GitHub Copilot, and Google Antigravity) are based on official documentation at the time of writing, while others are provided as best-effort presets. All paths can be customized, added, or disabled in the Settings screen.
